# BrainMap

**Turn your notes, bookmarks and code snippets into a map of connected ideas.**

A ByteForge Studios app.

## Download

**[Download BrainMap for Windows](https://github.com/azaan-ship-it/BrainMap/releases/latest/download/BrainMap-Setup-1.1.0.exe)**

Or grab it from the [Releases](https://github.com/azaan-ship-it/BrainMap/releases) page. Windows may show a SmartScreen warning because the app isn't signed yet: click **More info → Run anyway**.

## Use it on the web

**[Open BrainMap in your browser](https://byteforge-brainmap.web.app)**, no install needed.

## Features

- Write notes, save links and keep code snippets, all on one map
- Link ideas with [[double brackets]] and watch the connections appear
- Click any idea to see everything related to it
- Tags, colors, search and filters
- Attach files and images to notes
- Import and export Markdown
